# North Star

NormShift is an evidence-backed semantic diff engine for technical standards.

## Purpose

Determine how **normative requirements** change between two versions of a
technical document — not merely which words changed.

It tracks what implementers are **required**, **forbidden**, **recommended**,
or **permitted** to do.

## Long-term vision

> Build a verifiable temporal graph of what a technical standard required,
> when each requirement existed, and how each requirement changed over time.

## M0

M0 is a local-HTML vertical slice only: deterministic extraction, alignment,
classification, evidence-linked reports, and integrity verification — without
network, LLMs, embeddings, databases, or hosted services.
