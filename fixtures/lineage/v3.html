Lineage Demo 3

Definitions

session token is defined as a credential that authenticates a browser session for at most one origin unless private mode is active.

Session

Authenticated user agents MUST retain session token for 24 hours unless private mode is active.

Servers MUST validate client certificates and channel bindings on every request.

Clients MUST refresh access tokens before expiry.

Clients MUST refresh refresh-tokens before expiry.

Clients MUST NOT log raw session token values.
