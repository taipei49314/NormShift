Synthetic Protocol Spec 1.0.0

1 Transmission

Implementers SHOULD send an acknowledgment after each frame.

Servers MUST retry failed deliveries up to three times.

Clients MUST log every authentication failure.

2 Privacy

Implementers MUST store credentials in encrypted form.

User agents SHOULD cache public keys for at most 24 hours.

3 Examples

Example only: the client MUST send a heartbeat every second.

// pseudo: agent MUST ignore this line
send("ping");

The mustard configuration key MAY be omitted by clients.

A legacy peer is not required to support compression.

4 Routing

Implementers MUST reject unknown critical extensions.

Implementers MUST accept unknown non-critical extensions.

5 Session

User agents MUST open at most one control channel per origin.
