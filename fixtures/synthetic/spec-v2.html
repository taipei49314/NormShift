Synthetic Protocol Spec 2.0.0

1 Transmission

Implementers MUST send an acknowledgment after each frame.

Servers SHOULD retry failed deliveries up to three times.

Clients MUST NOT log every authentication failure.

Implementers MUST store credentials in encrypted form.

User agents SHOULD cache public keys for at most 24 hours unless private mode is active.

Implementers MUST synchronize clocks when a network is available.

Senders MUST include a monotonic sequence number on every datagram.
